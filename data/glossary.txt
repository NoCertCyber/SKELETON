    Wireshark is the GUI packet analyser: powerful display filters,
    Follow-Stream to read a conversation, Statistics for conversations /
    protocol-hierarchy / IO graphs, Export Objects to carve transferred files,
    and TLS decryption with a key-log file. The deep-dive tool once tshark or
    NetworkMiner has pointed you at the interesting traffic.
    • display filters: ip.addr==10.0.0.5 && tcp.port==445 ; http.request ; dns ; tcp.flags.syn==1 && tcp.flags.ack==0 ; frame contains "password"
    • right-click a packet -> Follow > TCP/HTTP/TLS Stream ; Statistics > Conversations / Protocol Hierarchy / IO Graph ; Expert Info
    • File > Export Objects > HTTP/SMB/TFTP to carve transferred files ; decrypt TLS via Preferences > Protocols > TLS > (Pre)-Master-Secret log
    • Analyze > Expert Info for retransmits / resets ; coloring rules and profiles per investigation type
